# Lost Grotto

This is a Rain World region mod developed by the FloodForge community.

## Installation

1. Clone the repo (`git clone https://github.com/Haizlbliek/Lost-Grotto.git`)
2. Symlink the `mod` folder into Rain World's `StreamingAssets/mods` folder
	A. For Linux, run the `link.sh` script
	B. For Windows, double click the `link.bat` script
